# SiNiSaveFilar2 - SiNiSistar2 Save Tool

**SiNiSistar2** 専用に設計された、多言語対応のセーブデータ復号化・再パックツールです。

## 主な機能
- **対話型 TUI**: 使いやすいターミナルユーザーインターフェース。多言語（英語、簡体字中国語、繁体字中国語、日本語）を完全サポート。
- **難読化されたセーブの復号化**: ゲームの難読化されたセーブデータ（`File01` や `System` など）を安全に読み込み、サムネイル画像を保持したまま、読みやすく編集可能な `.json` 形式に復号化します。
- **自動バックアップ**: 復号化操作を実行する前に、元のセーブデータのバックアップを自動的に作成し、偶発的なデータ損失を防ぎます。
- **スマート再パック (Encode)**: 変更したJSONデータを、ゲームエンジンが読み込めるようにネイティブの難読化・エンコード形式にシームレスに再パックします。

## 使用方法
1. `SiNiSaveFilar2.ps1` と `Run_SiNiSaveFilar2.bat` を SiNiSistar2 のセーブデータと同じディレクトリに配置します。
   - *Windows のデフォルト保存パス:* `%USERPROFILE%\AppData\LocalLow\Uu\SiNiSistar2\SaveData`
2. **`Run_SiNiSaveFilar2.bat`** をダブルクリックしてツールを起動します。
   - *(注: `.bat` ファイルを使用すると、PowerShell の実行ポリシー制限を自動的にバイパスし、ダブルクリックで安全にスクリプトを実行できます)*。
3. 画面上の TUI に従って言語を選択し、操作を選びます。
   - **[1] 復号化 (Decode Saves)**: セーブデータを新しく作成された `<timestamp>_SaveData_decoded` フォルダに抽出し、元のファイルを `<timestamp>_SaveData_backup` にバックアップします。
   - **編集 (Edit)**: 抽出された `.json` ファイルをテキストエディタ（メモ帳や VSCode など）で開き、`m_PlayerName` やアイテム、ステータスなどのゲーム内変数を変更します。
   - **[2] 暗号化 (Encode Saves)**: ツール内で変更したフォルダを選択し、編集した JSON を `<timestamp>_SaveData_encoded` に再パックします。
4. 再パックされた新しいファイルを `encoded` フォルダからルートの `SaveData` ディレクトリにコピーし、元のファイルを上書きします。
5. ゲームを起動して、変更を楽しみましょう！
